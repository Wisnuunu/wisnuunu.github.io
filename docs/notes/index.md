## Writing style

Notes here are meant to be quick to scan: short headings, concrete examples,
useful references. Prefer "here's how I solved X" over "here's a textbook
chapter".

When a topic grows beyond a few notes, give it its own folder and link to the
first note below each heading on this page, e.g.:

```md
### Frontend
- [Vue composition patterns](/notes/frontend/vue-composition-patterns)
```
